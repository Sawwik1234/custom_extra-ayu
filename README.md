# Custom Extra Ayu

Плагин кастомизации для **exteraGram**: живые обои в чатах, свои темы и скины.
Автор: [@sawwik1234](https://t.me/sawwik1234).

- Платформа: exteraGram **12.5.1+** (проверено на 13.1.1), SDK плагинов **1.4.6.3**, Python 3.11
- Android: **10 (API 29) и новее**
- Формат: Elyx-архив `.elyx` (Python-плагин, ставится через «Плагины → Установить»)

## Что умеет

**Живые обои**
- 4 типа анимации: анимированный градиент, параллакс-картинка, частицы (снег, звёзды, пузырьки, дождь), видео/GIF-цикл
- области: чаты, список чатов, весь интерфейс — включаются отдельно
- источники: встроенные палитры, файл из галереи/файлового менеджера, ссылка (скачивание с кэшем)
- переопределение на конкретный чат через меню сообщения, профиля и меню чата
- затемнение, отдельное затемнение для тёмной темы, масштаб, сдвиг, скорость, плавные переходы

**Темы**
- акцент, пузыри входящих/исходящих, шапка, фон, прозрачность пузырей
- создание темы из текущего вида, применение и сброс без перезапуска
- импорт/экспорт JSON, предупреждение о низком контрасте

**Скины**
- режим «цвета и градиенты» — работает всегда
- режим «подмена текстур» — свои картинки для пузырей, панели ввода и шапки (если клиент позволяет, иначе автоматический откат)
- импорт скина, папка `plugins/custom_extra_ayu/skins/<id>/`

**Производительность**
- лимит кадров, пауза при скролле, при бездействии и в фоне, качество текстуры, экономный режим одним переключателем
- ноль Python-кода в кадре: рисование в Java-объектах (Drawable/View/SurfaceView), Python только настраивает

**Логирование и диагностика**
- собственный слой `ayu_log.py`: уровни (verbose/debug/info/warning/error), теги по модулям, кольцевой буфер на 400 записей
- дедупликация через `logger.once(...)` — горячие пути (кадры, декодирование, отсутствующие классы) не спамят logcat
- замеры времени через `with logger.timed("...")`, `logger.exception` с трейсбеком, `logger.dump` для объектов
- «Скопировать лог» отдаёт окружение + реальные последние строки, а не сводку
- версия клиента и Android, какие хуки удалось подключить, число событий, последняя ошибка
- переключатель уровня логов прямо в настройках (`Debug` включает подробный вывод)

## Сборка

```bash
python3 tools/elyx_pack.py            # → builds/custom_extra_ayu-<version>-<date>.elyx
python3 tools/elyx_pack.py --compile  # тот же архив + байткод Python 3.11 (.pyc)
```

Архив кладётся в `builds/`, ставится в приложении: **exteraGram Preferences → Plugins → Установить**.

Альтернатива — официальный CLI:

```bash
python -m pip install --upgrade ElyxBuilder
elyb build -c 2 -v -nf
```

## Разработка

```bash
python3 tools/smoke_test.py   # прогон логики на фейковом хосте
```

Тест поднимает заглушки SDK, загружает плагин целиком, строит все страницы настроек,
проверяет цвета, настройки, темы и переопределения. Не заменяет проверку на телефоне,
но ловит ошибки импортов и подписей до установки.

Живая отладка на устройстве:

```bash
adb forward tcp:42690 tcp:42690
adb logcat -s plugin.custom_extra_ayu
```

## Структура

```
refmap.yml           Elyx: карта файлов
metainfo.yml         метаданные плагина
locales/             ru + en
res/                 ассеты
main.py              класс плагина, меню, импорт, диагностика
ayu_log.py           логирование: уровни, теги, буфер, таймеры
ayu_prefs/files/net  настройки, файлы, сеть
ayu_colors/theme     цвета и применение темы
ayu_engine.py        тик-драйвер кадров
ayu_javabridge.py    рефлексия в Java-классы клиента
ayu_wallpaper.py     сервис обоев, экраны, переопределения на чат
ayu_render_*.py      рендереры: gradient, parallax, particles, video
ayu_themes.py        модель тем и превью
ayu_skins.py         реестр скинов, ayu_skin_apply.py — применение
ayu_pages.py         страницы настроек; ayu_compose, ayu_bulletin, ayu_dialogs — их составные части
tools/               сборка архива и смоук-тест
docs/SPEC.md         техническое задание
```

Все модули — плоские файлы в корне архива. Иначе нельзя: Elyx создаёт пакеты с
пустым `__path__`, поэтому `import core` проходит, а `import core.assets` падает
с «unknown location». Префикс `ayu_` заменяет бывшие каталоги.

## Проверки

```bash
python3 tools/smoke_test.py                              # 10 проверок по репозиторию
python3 tools/elyx_pack.py                               # сборка архива
python3 tools/verify_archive.py builds/*.elyx            # загрузка архива как в движке
```

`tools/verify_archive.py` распаковывает готовый `.elyx` и выполняет его так, как это
делает движок Elyx: entry из `refmap.yml`, импорты от корня плагина, пакеты с пустым
`__path__`, конструктор `PluginClass(plugin_id, plugin_path)`, затем
`on_plugin_load` / `create_settings` / `on_plugin_unload`. Ловит имена атрибутов,
которых у `ElyxPlugin` нет, и раскладку файлов — до установки на телефон.

## Логи

```bash
adb logcat -s plugin.custom_extra_ayu
```

Каждая строка помечена тегом модуля: `[plugin]`, `[attach]`, `[wallpaper]`,
`[render.video]`, `[skins]`, `[themes]`, `[reflect]`, `[net]`, `[engine]`.

Типичный вывод при старте:

```
I/plugin: bootstrap: log level info, buffer 1
I/wallpaper: source refreshed: builtin:ayu_aurora, kind=gradient, local=no
I/attach: probe: ChatActivity=ok, ChatMessageCell=ok, RecyclerListView=ok, Theme=ok
I/plugin: loaded Custom Extra Ayu v1.0.0 | wallpaper=True kind=gradient | skins=False | android API 33
```

Уровни:

| Уровень | Что пишет |
| --- | --- |
| `verbose` | каждый кадр/пауза, разрешения классов, цвета темы |
| `debug` | подключение фона, декодирование картинок, кэш, скины |
| `info` | загрузка/выгрузка, источник фона, скачивание, применение темы |
| `warning` | недоступная внутренность клиента, битый файл, видео не запустилось |
| `error` | исключения с трейсбеком |

BUFFER_SIZE = 400 строк — меняется константой в `ayu_log.py`.

## Файлы плагина на устройстве

```
plugins/custom_extra_ayu/
├── cache/           скачанные и скопированные файлы
├── backgrounds/     сюда можно класть свои фоны
├── skins/<id>/      скины (skin.json + картинки)
├── themes/          резерв
├── overrides.json   обои для отдельных чатов
└── themes.json      список тем
```

не связан с командой exteraGram.
