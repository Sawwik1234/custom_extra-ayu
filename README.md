# Custom Extra Ayu

Плагин кастомизации для **exteraGram**: живые обои в чатах, свои темы и скины.
Автор: [@sawwik1234](https://t.me/sawwik1234).

- Платформа: exteraGram **12.5.1+** (проверено на 13.1.1), SDK плагинов **1.4.6.3**, Python 3.11
- Android: **10 (API 29) и новее**
- Формат: Elyx-архив `.elyx` (Python-плагин, ставится через «Плагины → Установить»)

## Что умеет

**Живые обои**
- 4 типа анимации: анимированный градиент, параллакс-картинка, частицы (снег, звёзды, пузырьки, дождь), видео/GIF-цикл
- области: чаты, список чатов, весь интерфейс — включаются отдельно
- источники: встроенные палитры, файл из галереи/файлового менеджера, ссылка (скачивание с кэшем)
- переопределение на конкретный чат через меню сообщения, профиля и меню чата
- затемнение, отдельное затемнение для тёмной темы, масштаб, сдвиг, скорость, плавные переходы

**Темы**
- акцент, пузыри входящих/исходящих, шапка, фон, прозрачность пузырей
- создание темы из текущего вида, применение и сброс без перезапуска
- импорт/экспорт JSON, предупреждение о низком контрасте

**Скины**
- режим «цвета и градиенты» — работает всегда
- режим «подмена текстур» — свои картинки для пузырей, панели ввода и шапки (если клиент позволяет, иначе автоматический откат)
- импорт скина, папка `plugins/custom_extra_ayu/skins/<id>/`

**Производительность**
- лимит кадров, пауза при скролле, при бездействии и в фоне, качество текстуры, экономный режим одним переключателем
- ноль Python-кода в кадре: рисование в Java-объектах (Drawable/View/SurfaceView), Python только настраивает

**Диагностика**
- версия клиента и Android, какие хуки удалось подключить, число событий, последняя ошибка, копирование лога одной кнопкой

## Сборка

```bash
python3 tools/elyx_pack.py            # → builds/custom_extra_ayu-<version>-<date>.elyx
python3 tools/elyx_pack.py --compile  # тот же архив + байткод Python 3.11 (.pyc)
```

Архив кладётся в `builds/`, ставится в приложении: **exteraGram Preferences → Plugins → Установить**.

Альтернатива — официальный CLI:

```bash
python -m pip install --upgrade ElyxBuilder
elyb build -c 2 -v -nf
```

## Разработка

```bash
python3 tools/smoke_test.py   # прогон логики на фейковом хосте
```

Тест поднимает заглушки SDK, загружает плагин целиком, строит все страницы настроек,
проверяет цвета, настройки, темы и переопределения. Не заменяет проверку на телефоне,
но ловит ошибки импортов и подписей до установки.

Живая отладка на устройстве:

```bash
adb forward tcp:42690 tcp:42690
adb logcat -s plugin.custom_extra_ayu
```

## Структура

```
refmap.yml           Elyx: карта файлов
metainfo.yml         метаданные плагина
locales/             ru + en
res/                 ассеты
src/main.py          класс плагина, меню, импорт, диагностика
src/core/            настройки, файлы, сеть, цвета, тема, движок кадров, рефлексия
src/wallpaper/       сервис обоев, установка на экраны, рендереры
src/themes/          модель тем и превью
src/skins/           реестр и применение скинов
src/ayu_ui/          страницы настроек и диалоги
tools/               сборка архива и смоук-тест
docs/SPEC.md         техническое задание
```

## Файлы плагина на устройстве

```
plugins/custom_extra_ayu/
├── cache/           скачанные и скопированные файлы
├── backgrounds/     сюда можно класть свои фоны
├── skins/<id>/      скины (skin.json + картинки)
├── themes/          резерв
├── overrides.json   обои для отдельных чатов
└── themes.json      список тем
```

## Лицензия

Код плагина — для личного использования и модификации. Неофициальный плагин,
не связан с командой exteraGram.
