# Custom Extra Ayu — техническое задание

Плагин кастомизации для exteraGram: живые обои и фоны, собственные темы и скины
(подмена текстур пузырей и панелей), полная настраиваемость из UI плагина.

Статус документа: **согласовано, реализация не начата**.

---

## 1. Позиционирование

Один плагин, который закрывает три связанные задачи оформления:

| Блок | Что даёт |
| --- | --- |
| **A. Обои** | Живой фон (видео/GIF-цикл, частицы, параллакс, градиент/Lottie) в чате, списке чатов и остальных экранах, с переопределением на конкретный чат |
| **B. Темы** | Свои темы: цвета, градиенты, фон, прозрачность — с превью и импортом/экспортом |
| **C. Скины** | Подмена картинок пузырей сообщений, шапки и панели ввода на свои текстуры |

Сквозные принципы:

1. **Ничего не захардкожено.** Любой параметр, влияющий на внешний вид или
   производительность, вынесен в настройки плагина.
2. **Деградация без падения.** Если API клиента недоступен (другая версия,
   другой форк), функция отключается и пишет понятную причину в лог и в UI, а
   не роняет плагин целиком.
3. **Пользователь видит, что происходит.** Отдельный раздел «Диагностика»:
   что включено, что не удалось, версия клиента, найденные хуки, FPS.

## 2. Платформа и совместимость

| Параметр | Значение |
| --- | --- |
| Клиент | exteraGram **13.1.1** (основная цель) |
| SDK | **1.4.6.3** → доступны multi-account, `IntentsManager`, Elyx, `FilesController` с иконками |
| Python | 3.11 (Chaquopy) |
| `__app_version__` | `>=12.5.1` (мягкий минимум), `__sdk_version__ = ">=1.4.6.3"` |
| Формат на старте | один `.py`-файл, структура модулей — под будущий Elyx |
| Языки | ru + en |

Зависимости: только предустановленные (`requests`, `pillow`, `lxml`, `PyYAML`).
`__requirements__` на старте пустой — плагин ставится без сети.

## 3. Архитектура

Старт как один файл, но код сразу разложен по слоям, чтобы переезд на Elyx был
механическим (вынести слои в `src/*.py` + `metainfo.yml` + `locales/`).

```
custom_extra_ayu.py        # entry: метаданные, класс плагина, регистрация
├── core/settings_model    # типы настроек, дефолты, миграции, валидация
├── core/prefs             # обёртка над get_setting/set_setting + кэш значений
├── core/assets            # источник фона: bundled | gallery | url, кэш файлов
├── core/engine            # тик-драйвер анимации, единый для всех экранов
├── wallpaper/renderer     # video / particles / parallax / gradient-lottie
├── wallpaper/attach       # внедрение в ChatActivity, DialogsActivity и др.
├── wallpaper/per_chat     # переопределения на dialog_id
├── themes/model           # схема темы, экспорт/импорт, применение
├── themes/apply           # применение цветов/градиентов к текущей теме
├── skins/registry         # пары "логический элемент → свой drawable"
├── skins/hook             # хуки подмены drawable
└── ui/pages               # страницы настроек и превью
```

Правила: никакой работы с сетью/диском в UI-потоке (всё через
`run_on_queue`), все хуки обратимы, в `on_plugin_unload` останавливаются
таймеры и слушатели.

## 4. Блок A — живые обои

### 4.1 Типы анимации (все, переключаемо)

| Тип | Суть | Основной риск |
| --- | --- | --- |
| **Видео / GIF-цикл** | Короткое видео или GIF в бесконечном цикле как фон | Расход батареи, декодирование, звук должен быть отключён |
| **Частицы** | Снег, звёзды, пузырьки, дождь, «пыль» — рисуется на Canvas | Плавность при скролле, число частиц |
| **Параллакс** | Фон медленно смещается/масштабируется при скролле и смене чата | Требует доступа к смещению списка сообщений |
| **Градиент / Lottie** | Переливающийся градиент или Lottie-анимация | Совместимость Lottie-рендера |

Каждый тип — независимый модуль с общим интерфейсом
`create / attach / tick / pause / resume / detach`, чтобы движок мог держать
один тип на экран и переключать их без перезапуска приложения.

### 4.2 Где применяется

- экран чата;
- список чатов (главный экран);
- остальные экраны приложения (единый фон);
- каждый уровень включается отдельно в настройках.

Переходы между экранами: фон не «прыгает» — при смене экрана используется
плавное появление/затухание, длительность и кривая — в настройках
(«Плавные переходы: длительность, мс»).

### 4.3 Источники фона

1. **Встроенные** — набор демонстрационных фонов внутри плагина (маленькие,
   чтобы не пух архив; частицы и градиенты генерируются кодом вообще без файлов).
2. **Галерея / файлы** — выбор файла, копирование в папку плагина, кэш.
3. **URL** — скачивание по ссылке с кэшем и проверкой размера/типа; обновление
   фона без переустановки плагина.

Общие правила: файлы складываются в `plugins/custom_extra_ayu/…`,
нечитаемый/битый файл не применяется и даёт понятное сообщение, кэш очищается
отдельной кнопкой.

### 4.4 Переопределение на чат

Глобальный фон по умолчанию + персональный для отдельного чата. Точки входа —
все три:

- контекстное меню сообщения → «Обои этого чата»;
- меню профиля/шапки чата → «Обои чата»;
- контекстное меню диалога в списке чатов.

Хранилище: `dialog_id → профиль фона` (свой источник + свои параметры
анимации/яркости). Отдельный экран «Чаты с особыми обоями» со сбросом.

### 4.5 Параметры оформления фона

- затемнение (0–100 %) и его изменение в тёмной/светлой теме отдельно;
- размытие фона;
- насыщенность/яркость/контраст;
- скорость анимации;
- масштаб и позиция (заполнить/вписать/растянуть, сдвиг, поворот);
- видимость фона в пузырях сообщений, только под ними, или только в «пустых» зонах.

## 5. Блок B — темы

- **Модель темы**: имя, акцентный цвет (+ авто-акцент из картинки), фон,
  цвета пузырей входящих/исходящих, прозрачность панелей, цвет шапки, скругления,
  шрифт (если доступен), обои по умолчанию.
- **Превью в реальном времени**: образец чата (входящее/исходящее сообщение,
  шапка, панель ввода) прямо на странице настроек; изменения видны без выхода.
- **Управление**: список тем, создание/дублирование/удаление/переименование,
  выбор активной, импорт/экспорт файла темы.
- **Совместимость**: тема хранится как данные плагина, а не как `.attheme`;
  опционально — экспорт в `.attheme` для переноса в другие клиенты.
- **Безопасность**: применение темы не должно ломать читаемость — если
  контраст текста падает ниже порога, плагин предупреждает и предлагает
  исправить автоматически.

## 6. Блок C — скины

Уровень «глубже, чем цвета»: свои картинки для элементов интерфейса.

| Элемент | Что подменяется |
| --- | --- |
| Пузырь входящего / исходящего | фон, «хвост», состояние «нажато» |
| Панель ввода | фон, поле ввода, кнопки |
| Шапка | фон/градиент |
| Разделители, выделение диалога | свои текстуры |

Механика:

1. **Подмена drawable** — приоритетный путь: свои 9-patch/PNG/SVG на элемент.
2. **Перекраска и градиенты** — быстрый и надёжный путь для случая, когда
   подмена на текущей версии клиента недоступна.
3. Хранилище скина — папка внутри плагина: `skin.json` + картинки; скин можно
   экспортировать архивом и передать другому пользователю.
4. Каждый элемент подключается отдельно и может быть выключен, если на
   конкретной версии клиента он выглядит некорректно.

## 7. Настройки (полный перечень страниц)

Плоская структура, вложенные страницы через `create_sub_fragment`.

1. **Обои**
   - вкл/выкл, тип анимации (видео / частицы / параллакс / градиент-Lottie);
   - применение: чат, список чатов, весь интерфейс;
   - источник фона: встроенный / файл / URL + кнопка «Скачать/Выбрать»;
   - затемнение, размытие, насыщенность, скорость, масштаб, позиция;
   - плавные переходы: вкл, длительность.
2. **Частицы**
   - тип эффекта, количество, размер, скорость, направление, цвет, прозрачность.
3. **Темы**
   - активная тема, список тем, редактор, превью, импорт/экспорт.
4. **Скины**
   - активный скин, по элементам: пузыри (вх./исх.), панель ввода, шапка,
     разделители; импорт/экспорт скина; «Проверить на этом клиенте».
5. **Чаты с особыми обоями**
   - список переопределений, сброс одного/всех.
6. **Производительность**
   - FPS-лимит, пауза при скролле (вкл/выкл, задержка), пауза в фоне,
     пауза при бездействии (таймаут), качество текстуры (понижение разрешения),
     «экономный режим» одной кнопкой.
7. **Диагностика**
   - версия клиента/SDK, доступность API по каждому блоку, найденные хуки,
   - текущий FPS и средняя нагрузка, кнопка «Скопировать лог» (`copy_to_clipboard`),
   - кнопка «Сбросить всё к значениям по умолчанию».

Все значения — через `get_setting/set_setting`; изменение, влияющее на состав
строк, вызывает `reload_settings=True`.

## 8. Производительность

Полностью управляемо пользователем, с безопасными дефолтами:

- лимит FPS (по умолчанию 30 для видео, 60 для частиц с малым числом);
- пауза анимации при скролле списка сообщений и при вводе текста;
- полная остановка при уходе в фон (`AppEvent.PAUSE`) и при погашенном экране;
- пауза после N секунд бездействия (по умолчанию 15 с);
- уменьшение разрешения текстуры на слабых устройствах;
- «экономный режим» — один переключатель, включающий всё перечисленное.

## 9. Локализация

ru и en с самого начала, ключи семантические (`settings_wallpaper_title`),
плейсхолдеры через `{name}`. На старте — словарь в коде, при переезде на Elyx —
`locales/strings_ru.yml`, `locales/strings_en.yml` без правки логики.

## 10. Логирование и диагностика

`self.logger` (тег `plugin.custom_extra_ayu`), аргументы вместо f-строк в
горячих путях, `logger.exception` в `except`. Уровень по умолчанию — INFO,
DEBUG включается в «Диагностике». Каждое отключение функции сопровождается
одной понятной записью с причиной, а не молчанием.

## 11. Риски и как закрываем

| Риск | Реакция |
| --- | --- |
| Внутренние классы клиента меняются между версиями | Каждая точка внедрения ищется через `find_class` с проверкой на `None`; при провале — функция отключается, остальное работает |
| Подмена drawable ломает рендер пузырей | Отдельный выключатель на каждый элемент + автоматический откат к перекраске |
| Живое видео «съедает» батарею и тормозит скролл | Лимит FPS, паузы, понижение качества, экономный режим |
| Пер-чат обои конфликтуют со штатными обоями Telegram | Плагин слоем выше штатного фона, штатные обои не изменяются в базе |
| Нет возможности прогнать на устройстве в моей среде | Код пишется с проверками и подробными логами; отладка итеративная по вашим логам |

## 12. Этапы

| Этап | Содержание | Проверяемый результат |
| --- | --- | --- |
| **M1** | Каркас плагина, настройки, диагностика, движок анимации + параллакс и градиент | Включается/выключается живой фон в чате, параметры меняются на лету |
| **M2** | Частицы (снег/звёзды/пузырьки) + паузы и FPS-лимит | Эффекты работают плавно, скролл не тормозит |
| **M3** | Видео/GIF-цикл, выбор файла из галереи и по URL, кэш | Свой видеофон применяется и сохраняется между запусками |
| **M4** | Пер-чат переопределения + три точки входа в меню | Можно задать отдельный фон конкретному чату |
| **M5** | Темы: модель, превью, список, импорт/экспорт | Своя тема создаётся и применяется без перезапуска |
| **M6** | Скины: подмена drawable + перекраска, импорт/экспорт скина | Свои текстуры пузырей и панели ввода |
| **M7** (опц.) | Переезд на Elyx: `refmap.yml`, `locales/`, `res/`, сборка ElyxBuilder | Плагин ставится архивом `.elyx`, ru/en из файлов |

Порядок этапов можно менять — например, если скины нужны раньше, чем видео.

## 13. Что потребуется при тестировании

- `adb logcat -s plugin.custom_extra_ayu` (или скриншот раздела «Диагностика»);
- версия клиента и модель устройства при отчёте о проблеме;
- один-два тестовых видео/GIF и картинки для скинов — для проверки на реальных данных.
